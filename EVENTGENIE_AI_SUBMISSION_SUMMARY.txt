EVENTGENIE AI - PROJECT SUBMISSION & DEPLOYMENT SUMMARY
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Project Name    : EventGenie AI
Tagline         : Intelligent Event Planning, Smart Budget & Timelines
Repository      : https://github.com/shobhit5kumar/event-geneiue
Target Platform : Web Application (Desktop, Tablet, Mobile)
Architecture    : HTML5, Vanilla CSS3 (Custom Design System), ES6+ JavaScript,
                  Python 3 Backend API / Vite Build Tooling for Vercel


2. CHANGES & UPDATES MADE IN THE DEPLOYED VERSION (~1,000 CHARACTERS)
--------------------------------------------------------------------------------
• UI/UX Design System: Built a responsive glassmorphic UI using a deep navy (#0B1120), violet (#7C3AED), and cyan (#38BDF8) palette. Features a high-converting landing page, 6-tab dashboard, interactive modals, and toast notifications.
• AI Event Plan Synthesis: Multi-step wizard supporting weddings, birthdays, fests, and galas. Generates tailored vision statements, capacity-matched venues, decor/lighting concepts, catering menus, and entertainment schedules.
• Smart Programmatic Budget: Strict arithmetic calculation engine (no LLM math errors). Features real-time sliders for guest/budget recalculation, itemized cost tracking, paid escrow toggles, and over-budget alerts.
• Checklist & Run Sheet: Phased preparation timeline (6+ months to event day) with priority filters, progress tracking, and an hour-by-hour event-day operational schedule.
• Vendor Hub: Category negotiation guides with interview questions and red flags, plus a custom directory for confirmed vendor quotes.
• Deployment & Persistence: Added Vite & vercel.json for instant cloud hosting, dual JSON/localStorage sync, and 3 rich sample events.


3. GENERATIVE AI SERVICES UTILIZED & WHERE THEY ARE IMPLEMENTED
--------------------------------------------------------------------------------
A. Generative AI Service:
   - Primary: Google Gemini API (gemini-1.5-flash / gemini-2.0 models) via a secure
     backend proxy (server-side environment variable GEMINI_API_KEY).
     API keys are never exposed in frontend code.
   - Fallback / Demo Engine: Built-in Smart Offline Contextual Domain Engine
     (Demo AI Mode) that provides immediate, fully functional domain reasoning
     without requiring an API key.

B. Where Generative AI is Utilized in the Application:

   1. AI Master Plan Synthesis (/api/ai/plan):
      - Executive Summary & Theme Narrative: Generates cohesive vision concepts
        tailored to the host, occasion, and guest count.
      - Venue Matching: Analyzes scale and budget to propose 2-3 curated venue
        concepts with capacity fit, pros, cons, and cost expectations.
      - Decor & Ambience Architecture: Designs entrance focal points, table styling,
        lighting schemes, and custom interactive photo installations.
      - Culinary & Beverage Blueprint: Formulates multi-course catering menus,
        dietary accommodations (Vegan/GF), and signature cocktail/mocktail recipes.
      - Entertainment Flow: Plans musical genres, timeline cues, and audience
        engagement moments.

   2. Conversational Event Co-Pilot (/api/ai/chat):
      - Context-Aware Event Consultation: Chat assistant receives the full context
        of the active event (title, type, guest count, budget, theme, location, date).
      - Budget Optimization Advisory: Generates high-impact, practical cost-saving
        strategies without sacrificing guest experience.
      - Guest Communication & Etiquette: Drafts polite, customized RSVP reminder
        templates for WhatsApp and Email.
      - Signature Beverage Mixology: Designs themed cocktails and zero-proof drinks
        with recipes, garnishes, and whimsical names.
      - Weather & Emergency Contingencies: Outlines actionable 72-hour rain
        contingency action plans and tent drainage logistics.
      - Schedule Bottleneck Analysis: Evaluates event-day timelines and recommends
        transitional buffers for speeches, dinner, and photography.

   3. Quick-Prompt Intelligence:
      - Powers interactive one-click prompt chips on the chat interface to deliver
        immediate event advice for non-technical hosts.
