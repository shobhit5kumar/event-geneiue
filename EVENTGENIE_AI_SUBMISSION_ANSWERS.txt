QUESTION 2: Mention the Gen AI services utilized, and where did you utilize it?
--------------------------------------------------------------------------------
EventGenie AI incorporates a dual-tier Generative AI architecture:

• Gen AI Service: Google Gemini API (gemini-1.5-flash / gemini-2.0) accessed through a secure server-side proxy (API key stored via server environment variables, never exposed to clients). It includes a built-in offline Contextual Domain Engine (Demo AI Mode) ensuring full operational availability.

• Where Gen AI is Utilized:
1. Event Plan Synthesis (/api/ai/plan): Generates tailored event narratives, venue recommendations with pros/cons, thematic decor/lighting concepts, multi-course catering menus with dietary options (Vegan/GF), signature cocktails/mocktails, and musical program highlights.
2. Conversational Co-Pilot (/api/ai/chat): A context-aware chat assistant that evaluates active event parameters (guests, budget, theme, location) to deliver budget-saving strategies, polite RSVP reminder drafts (WhatsApp/Email), 72-hour rain contingency protocols, and schedule bottleneck reviews.
3. Quick Prompt Chips: Delivers instant curated planning advice for non-technical event hosts.
