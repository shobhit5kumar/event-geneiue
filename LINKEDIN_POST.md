### Option 1: Engaging & Comprehensive (Recommended for Maximum Reach)

Planning an event shouldn't feel like managing a chaotic spreadsheet. Whether it's a botanical garden wedding, a 21st birthday bash, or a 500-attendee college festival, turning a celebration dream into an actionable reality is overwhelming. 

That’s why I built **EventGenie AI** 🧞✨ — an intelligent event planning assistant and financial co-pilot submitted for **[Challenge 5: Celebration & Event Planner]**!

💡 **What makes EventGenie AI different?**
Most AI tools generate generic text and hallucinate financial math. EventGenie AI bridges generative intelligence with **strict programmatic financial engineering**:

🔹 **AI Plan Synthesis:** Multi-step wizard generating tailored executive summaries, capacity-matched venue concepts (with pros/cons), decor blueprints, multi-course menus with dietary options (Vegan/GF), and entertainment flow.
🔹 **Deterministic Smart Budget:** Pure programmatic arithmetic calculations — zero LLM math errors. Interactive sliders for guests and budget automatically recalculate category baselines with itemized cost tracking.
🔹 **Milestone Checklist & Run Sheet:** Phased timeline (6+ months out to event day) paired with an hour-by-hour operational day schedule.
🔹 **Advisory Vendor Hub:** Negotiation guides with "Must-Ask Questions" and red-flag alerts, plus a private directory for confirmed vendor quotes.
🔹 **Conversational AI Co-Pilot:** Powered by the **Google Gemini API** with an offline heuristic engine fallback (Demo AI Mode) to brainstorm budget-saving tips, rain contingencies, and polite RSVP reminder drafts.

🛠️ **Tech Stack & Architecture:**
- **Frontend:** Semantic HTML5, Custom Vanilla CSS3 Design System (deep navy, violet & soft cyan glassmorphism), Modern ES6+ JavaScript.
- **Backend & AI:** Python 3 Standard Library server with secure Gemini proxy + Vite configuration for zero-config Vercel cloud deployment.
- **Data:** Dual-persistence (JSON file store + browser localStorage sync) with 3 rich pre-loaded sample events.
